## Vocabulary agent

- **Quantities code cannot parse.** `time_point` "half an hour" is a quantity in words (spec, tab 3: a number in words is a quantity), but code's number words lack "half". A quantity field takes no terms, so it is flagged *not a context*; the right fix is in code (number words), not in the record. "before cell cultivation" (time_point) and "end of cultivation" (day_of_measurement) are named moments, not numbers or declared states; flagged the same way.
- **Cell-free absorption chips (Fig. 1F, text).** "Biowire II chip" and "PDMS chip" are device pieces without cells; I added `platform:cell_free_device_chip` (device and material as qualifiers) rather than map the chip to the Biowire II tissue platform. "tissue culture well" is the dye-only control and maps to `platform:cell_free_control` without a synonym. The spec does not say how to place cell-free material tests in `platform`.
- **Biowire II** got its own family: `platform:tissue_between_wires` (under 3D engineered tissue) > `platform:biowire_ii`. Tissue held between two wires could also be read as a variant of *tissue between two pillars*.
- **"BJ1D + HES3" (Fig. 2G) flagged *several conditions***: each tissue came from one line and the paper does not say which line was used for which compound. "HES3 + BJ1D" (the atrioventricular tissues, both lines in one tissue) is a real set and is matched by code.
- **Ids not found:** BJ1D (Cellosaurus; own term), the six CDI patient lines Non-affected A–C and Affected D–F (own terms, no catalogue ids printed), left ventricular hypertrophy (MONDO; own term). MSC-iPSC1 is adopted as Cellosaurus MSC-iPS1 (CVCL_C961) because the paper cites Park et al. 2008. That match rests on the citation; the spelling differs.
- **"electrical conditioning"** maps to *intensity training* without a synonym, because every protocol here raises the frequency stepwise. **"elastic POMaC wires"** maps to *auxotonic*.
- **Measures that are not one measure:** "time-to-peak of force and Ca2+" and "decay time of force and Ca2+" are flagged *several measures*; "time to reach maximum stimulation rate" is flagged *not a context* (a protocol design, Fig. 3A). Heatmaps of named gene sets map to a new `measure:gene_set_expression` with `gene_set`, not one gene each.
- **Uncertain measure choices:** "electrical excitability" (lidocaine) → *presence of beating*; "contractile protein density" (qualitative histology) → *myofibrillar density*; "thapsigargin potency" → a new *compound potency, statistic not stated*. Mapping it to IC50 would invert the stated direction. "post-rest force" → twitch force with `contraction_mode: first beat after rest`.
- **Normalisations:** "normalized active force" maps to `normalised_to: force at 1 Hz` (Methods: "all measurements were normalized to the 1Hz baseline values"), and S4GJ/S4KN carry the same wording. "normalized post-rest potentiation" maps to `normalised_to: force at the last pacing frequency` (Fig. 4D legend).
- **Possible record issues (not fixed):** Fig. 1F's Rhodamine B is recorded as 1 µM, but the extracted Methods read "1 mM". This is probably the µ→m extraction artefact also seen in "650 mL" (a person should check the PDF). S4O's groups are other publications' tissues (Jackman, Tiburcy, Riegler, …): their values are cited, not measured here.
- "Kreb’s Solution or DMEM" (measurement_medium) is flagged *alternatives*.

## Formula agent

- **Library covered every step; no proposals.** Reused ratio_def, stress_def, sum_of_parts, part_of_whole, relative_change, normalized_to_own_control and fraction_bounds (73 derivations: 64 with a library formula, 9 with no_formula; 11 bounds).
- **Units code does not know:** "nN/Cell" (S4O force per input CM) and "CMs" (S4O input). Code left the rebuilt value in N, which made every row look inconsistent. I set `output_unit: nN` (nN per one CM; the count is dimensionless). The spec does not say whether "per cell" units belong in the unit table or in `output_unit`.
- **Observation for code: S4O Tiburcy row.** Active force 2.635 mN / 1.5x10^6 CMs = 1.76 nN/CM, but 1.12 is printed. The other five rows with both parts printed rebuild at printed precision. The Tiburcy force is also the only other-study force printed without an asterisk. The asterisk is never explained, so I read asterisked force-per-area values as taken from the cited studies, and derived force per area only for the Biowire II rows.
- **Biowire force per area:** the methods measure "tissue width (diameter)" but never state how the area was computed, and print no width or area. The area step is `no_formula`, with the circular section as a labelled alternative. The two printed rows imply about the same area (0.0025/0.051 ≈ 0.049 mm², 0.062/1.2 ≈ 0.052 mm²; diameter ≈ 0.25 mm). Code cannot check this without a printed width.
- **PRP normalization conflict:** Fig. 4D legend says PRP is "normalized to the last pacing frequency", but Methods say "all measurements were normalized to the 1Hz baseline values". I wrote the derivation from the legend, with the Methods version as an alternative. The printed "2.5-fold vs 6 Hz" matches the mean of the per-tissue F4D Ventricular ST readings (2.48). I could not link it, because the readings are of the ratio itself, not of its inputs.
- **dF/F0:** the methods call it "the ratio of peak tissue fluorescence intensity to baseline intensity", but the printed amplitudes (0.040–0.080) are below 1. A peak/baseline ratio cannot be below 1, so the values fit (peak − baseline)/baseline. I wrote the formula as stated, with the relative change as an alternative. No library bound says a peak/baseline ratio is ≥ 1, so code cannot flag this.
- **1 Hz normalized groups:** each tissue is normalized to itself (mean 1, SD 0). I wrote these as normalized_to_own_control with formula `r = F1/F1` (the stated r = F/F1 with F = F1). Writing `r = F/F1` with two separate symbols made code report it inconsistent. F4C and S4G–N test other frequencies against this group (the fold-change test issue).
- **Not derivable here:** conduction velocity (the method from activation maps is not stated), Young's modulus (by citation, ASTM D638-10 / Zhang 2016), IC50 (Prism curve fit) and force from wire deflection (empirical third-degree polynomial calibration, FEM-backed) are `no_formula`. APD30/APD90 cannot be rebuilt: APD90 is never read (F4GM has no points, and Fig. 7 does not show APD90).
- **Active force = total − passive** applies to every active-force item. I wrote one derivation per item; none prints total or passive tension.
