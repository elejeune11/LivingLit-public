## Vocabulary agent

- **`insulin_day` 'D7' flagged (*not a context*).** It is one context, but "D7" does not parse as a quantity (the digit follows a letter), and a quantity field takes no terms. No flag kind fits; *not a context* was the closest. The reader should write "day 7".
- **Maturation-medium components sit in `supplements`.** Palmitic acid, oleic acid and galactose vary between groups (GLUC vs MM), but the `supplements` scope says "the same across compared groups". I mapped the field as stated: I adopted CHEBI:7896 (hexadecanoate, already the treatment id for "palmitic acid") and CHEBI:16196 into `supplements` so code matches the set. Someone should decide whether varied energy substrates go to `treatment` or `maturation_strategy` (cross-field duplicate, re-map checkpoint).
- **'patterned surfaces' → new `platform:grooved_surface`** (lapping-paper grooves), not `micropatterned_culture`, whose definition is printed matrix islands. The main text itself says "micropatterned with grooves". 'flat surfaces' → `platform:monolayer`, so GLUC vs GLPAT come out as sibling terms (*differ*) and not as broader/narrower. Neither wording became a synonym, because both are too generic.
- **'vehicle' → `treatment:vehicle_not_stated`** with the qualifier control "vehicle". The methods name PBS (PE), DMSO (JQ1) and DMSO (DFO), and Fig. 7C says "DMSO vehicle". The reader could write the solvent per unit, e.g. "vehicle (PBS)".
- **Preparations inferred from the methods' next step.** 'frozen cell pellets' → `metabolite_extract` and 'flash frozen cells' → new `lipid_extract` (Bligh-Dyer). The stated words name the storage step, not the extract.
- **'hiPSCs' → CL:0002248 (pluripotent stem cell), `no_ontology_term`.** The pinned CL has no induced-PSC class.
- **DFO is the mesylate salt (CHEBI:748559)**, as the methods print it, not desferrioxamine (CHEBI:50453).
- **'resting tension' → `diastolic_stress`.** This is passive myofibril tension in mN/mm². The key's `preparation` keeps it apart from tissue diastolic stress. 'maximum tension' got its own term (`calcium_activated_tension`), so that it is not compared as twitch stress.
- **New myofibril kinetics tree:** `myofibril_rate_constant` with kACT, kTR, kREL slow and kREL fast as children, plus `slow_phase_relaxation_duration` (tLIN). The rate constants are in s⁻¹, which the unit parser does not read ("sec -1" has no dimension), so I gave them dimension *frequency*.

- **'polar metabolites'** → `metabolite_abundance` (all screened). Its values are counts (136 measured, 51 altered), not abundances. A count-of-altered-metabolites measure may be the better fit if other papers report the same.
