## Record reader

- **Regressions on age (Fig. 6C–H, Supplemental Figs. S1, S3).** Each panel is a linear regression of a measure on days in ECT culture (continuous x). The paper sets out no levels, so I wrote one group (`all`) per unit and one measurement item per panel. R² goes in `stats.statistic` and P in `stats.p`. Both are image-only figure text, so their anchors are `kind: unit`. The schema has no form for a regression slope, and no slope or direction is printed. Directions stated in the text are carried by the paired early-vs-late items (Table S1).
- **Regression day range.** The Methods say ECTs were cultured for 14–57 days, but the regression panels plot ages from about 8 to 70 days. I wrote `day_of_measurement: 14–57 days` with a suspected error and did not compute a range from the plot.
- **Force–frequency and Ca–frequency (Fig. 2D–K).** The tests are along pacing frequency, but no values or tests are printed per frequency, and some levels (0.75 Hz) appear only on the image axis. I wrote one group, paced "from 0.5 to 2.5 Hz", with measurement items whose findings are worded from the text. I did not invent per-frequency groups or pick a pair the paper does not print, so the frequency claims are judged *cannot judge* on support.
- **Early vs late difference in isoproterenol response (Table S3, "p = Early vs. Late", Student's t-test; S4 P = 0.843).** I recorded these as `test_of: interaction` over the four groups (late_iso, late_bl, early_iso, early_bl). The test is a t-test on % responses, which tests the same question as the interaction, but it is not an ANOVA interaction term.
- **Table S3 % responses.** The values in brackets after each Iso mean (e.g. "0.967 (42.52%)") and after each SEM ("0.040 (5.18%)") are recorded as `percent` and `sem` with `between: [iso, bl]` and `expressed_as: % change`. The CT50-100 and RT50-90 rows print identical % values (−4.462% (2.08%) early, −20.76% (1.34%) late), so I flagged them as a suspected error.
- **n conflict.** The Results give early (n = 10) and late (n = 13) for isoproterenol; Table S3 footnote 4 gives Early N = 10, Late N = 14. Both are recorded: the table n in `n`, the conflict as a suspected error on ST3_TF_*.
- **Table S2 "Fold Change".** The printed values equal (late/early − 1), for example MYL2 4.915 → 9.481 is printed 0.929. I recorded them as `kind: value`, unit "fold change", `between: [late, early]`, rather than as `ratio`, so that no check reads them as late/early.
- **MYH6.** Supplemental Fig. S5C marks early vs late with *, but Table S2 prints p = 0.1280. Both are recorded (`p_values`) with a suspected error.
- **Fig. 5E vs Table S3 (CT50, early).** The figure shows *, the table 0.0002**. Both are recorded; they do not contradict each other in direction.
- **S6 panels without marks (SLC8A1, TNNI1).** Recorded as omnibus items with p *not stated*: the legend names the tests, but no P or n.s. is printed for these panels.
- **ADRB1/ADRB2 early vs late (Fig. 5I).** No mark is shown, and the text says "not significantly different". I recorded this as a pair with p *not stated* and `stated_direction: none`.
- **Targeted RNAseq (TXT1).** The text puts ADRB1 and TNNI3 in early ECTs; for MYH7 and ACTC1 it does not say which age was measured. I put all four in the `early` group and noted it on TXT1_MYH7. The ± in these values (and in Table 1, Fig. 3 Bin1 spacing, and the 2.5 Hz responses) has no named spread, so the ± number is recorded as `kind: value`, `spread: none`, and the mean as `spread: not stated`.
- **Table 1 (comparison with literature).** One group per row (parameter × model), because each row cites a different set of references. A group carries one citation, so each row's printed reference list (e.g. "(42, 9, 47, 45, 48, 49, 19, 12)") is recorded as one citation entry with that label rather than as individual references. Native rows (Neonatal, Infant, Adult, Fetal, Adult LV, Adult (hLV)) are `native tissue` with `donor_age` as declared states; hiPSC models are `other study`. The Fetal TF row prints no reference. Qualitative cells (Present, Absent, Quiescent, FFR direction) are not numbers, so they are written into the item's `finding`, not `values`. I used `x: 1 Hz` for the "(1 Hz)" annotations. The hiPSC-ECT row matches the late group of Table S1, but Table 1 does not say so, so it is a separate group with `day_of_measurement: not stated`.
- **Values printed twice across units.** The hiPSC-ECT values in Table 1 (e.g. TF 11.8 ± 0.8) and the late values in Table S1 (11.77 ± 0.78) are in different units (T1, ST1), so the source-suffix rule for repeated values cannot link them. The schema has no cross-unit "same value" link.
- **differentiation_factors.** CHIR99021 and IWP-4 are stated about 50 words apart, and the Fig. 1A timeline (which prints "CHIR99201") is image text. No ≤30-word quote holds both, so the value carries an inline anchor on the CHIR99021 sentence with a note quoting the IWP-4 sentence, instead of a `context_anchors` entry.
- **supplements.** Fibrin ECT media also contains 1 µg/mL gentamicin. With it, the anchor quote runs to 31 words, so gentamicin is left out of the set. The base medium (high-glucose DMEM + F12) is named once as `cm_medium: fibrin ECT media`.
- **purity "≥95%".** The ≥ sign is lost in extraction. The value is written as printed on the page, and the quote holds 95%.
- **preparation for force/Ca.** The paper calls the prepared sample a "hiPSC-ECT construct". I used that wording rather than "intact tissue", which the paper never uses.
- **Optical mapping.** Blebbistatin (10–15 µM, extracted as mM) was written as a `treatment`. It is an excitation–contraction uncoupler applied for imaging, so it may belong in `measurement_medium`. That field has no slot for a drug.
- **Isoproterenol concentration.** The extraction gives "1 mM" (µ lost), and the supplementary docx prints "1 µM". I used "1 µM", anchored to Supplemental Fig. S3.
- **Missing from the schema.** There is no field for the stretch protocol of Fig. 2A ("stretched from 8.2 mm to 10.8 mm with 0.3 mm length increases"), so it went to `other_conditions`. There is also no seeding density for differentiation (1.5–2.0 × 10⁶ cells/well) separate from ECT formation; only the ECT formation density is recorded.
- **Not stated.** genotype, disease_model and donor_age are *not stated*: the paper never calls DF19-9-11T.H a healthy or control line. mechanical_load is also *not stated*: the constructs hang between nylon tabs of Tissue Train wells, but no load is named.

## Vocabulary agent

- **Code gap, not a vocabulary question.** `wnt_inhibition_days: Forty-eight hours` is a valid quantity, but code's number-word list stops at "twelve", so it is unmapped. A quantity field takes no terms, so I had to flag it (`not a context`, the closest kind). The fix is to write `48 h`, or to teach the parser compound number words.
- **Flags:** `day_of_measurement: Late` (F2m) is the paper's group label (`placeholder`). `platform: Various 3D hiPSC-CM models` (Table 1) is `several conditions`. The measures `concurrent Ca2+-transient and twitch force time course` (Fig. 2L) and `absolute maximum velocities of contraction and relaxation (+dF/dtmax, -dF/dtmax)` (Supp. Fig. S2A) are each `several measures`.
- **Split requests:** `RPMI B27` (cm_medium): B27 goes to supplements. `2D hiPSC-CM` (platform): hiPSC-CM goes to cell_types.
- **Record issue (reader).** The Table 1 literature groups (Adult LV, Neonatal, 2D hiPSC-CM, Rapidly paced EHT, Cardiopatch…) inherit this paper's ECT context through the unit: fibrin substrate, hiPSC-CFs, Krebs–Henseleit, cm_day_at_formation, and platform `engineered cardiac tissue` for the human-myocardium groups. Most of those fields are not stated for the cited sources. The "2D hiPSC-CM" split meets the inherited `hiPSC-CMs + hiPSC-CFs` cell_types. I treated that as a split request, not a contradiction, but it is close to one.
- **Twitch force in mN/mm².** `maximum twitch force` (ST1/ST3/S1/S4) and `twitch force` (Table 1) are printed in mN/mm², so I mapped both to twitch stress. That overrides code's synonym match of `twitch force` to twitch force for this paper.
- **`homogenized`** is matched by code to preparation *lysate* (an earlier synonym). Here it means TRIzol homogenisation for RNA, so *RNA extract* would be the better term. A vocabulary re-map should look at that synonym.
- **Platform.** `engineered cardiac tissue` → *TissueTrain* (Methods: FlexCell Tissue Train plate, nylon tabs). The name is generic, so it is not a synonym. `CMTs` → the broader *3D engineered tissue*, and `Rapidly paced` → the broader *electrical stimulation*, because the paper does not state the cited format or regime.
- **TDI** → {thyroid hormone (CHEBI:60311, newly adopted in treatment), dexamethasone, IGF-1}, per the Table 1 footnote. The footnote says "thyroid hormone", not T3.
- **Gene names as printed:** CACNA1 (Methods: CACNA1C) and GJA (Methods: GJA1). They are compared as text, so they will not meet CACNA1C or GJA1 elsewhere. Wordings that appear in both ST2 (GAPDH) and S6 (RNA input) carry no `normalised_to`. Those are MYL2, MYL7, RYR2, ATP2A2, PLN, SLC8A1, TNNI1 and TNNI3.
- **ADRB1 as % of ADRB1 + ADRB2** went to *transcript isoform fraction* to match the three true isoform shares beside it. ADRB1 and ADRB2 are separate receptor genes, so this stretches the term's definition.
- **New terms** under existing parents: time to +dF/dtmax (under time to partial contraction), +dF/dtmax→Fmax (under contraction deceleration time), Fmax→−dF/dtmax (under relaxation time) and Bin1 striation spacing (*T-tubule striation spacing*, under T-tubules). Root terms: dF/dt ratio and action potential origin. CT50-100 and RT50-90 are the parent measures with `level` as printed.

## Formula agent

- **Table S3 % responses (38 derivations, `relative_change`).** The table never names the bracketed % values. I anchored them to "expressed as % isoproterenol response" (Results, about automaticity) and read them as (Iso − BL)/BL. Aggregation is *not stated*. With means only, code rebuilds the ratio of means, and every one comes out *inconsistent* (e.g. automaticity early is 33.6 % rebuilt against 42.52 % printed). This fits a mean of per-tissue % changes, which cannot be checked without per-tissue values. The verdict comes from that one alternative. Code cannot run the other, so it should perhaps say *cannot check* rather than *inconsistent*.
- **RT50-90 % row.** It prints the CT50-100 values (−4.462 %, −20.76 %), as the reader flagged. Code labels ST3_RT50_90_early "constant factor 2: conclusion unaffected". That label is an artefact of a copied row, not a scaling error.
- **Supplemental Table 2 "Fold Change" (27 genes, `ratio_def`, as stated).** Every printed value equals late/early − 1, so all 27 come out *inconsistent* with the ratio. I listed the alternative "relative change (late − early)/early". Code does not seem to evaluate `alternatives` that carry a formula. If it did, all 27 would fit.
- **dF/dt ratio (−dFdt/+dFdt).** n−dF/dt is printed negative and the ratio positive, so a/b is off in sign. Its magnitude (0.640) also falls short of the printed 0.647, consistent with a mean of per-tissue ratios. I listed the magnitude ratio as an alternative. All 6 come out *inconsistent*.
- **Named intervals (24 derivations, all consistent).** CT50-100 = CT100 − CT50, RT50-90 = RT90 − RT50, Ca2+DT50-75 = Ca2+DT75 − Ca2+DT50, and time +dF/dtMax→FMax = CT100 − time to +dF/dtMax. For the last one I assumed both times share one origin (the stimulus). The paper does not state that.
- **Not checkable (written for completeness).** These are: TF in mN/mm2 (the normalisation is not stated, so `no_formula`); ΔΔCT relative expression (stated only by citation 28, "modified", so `no_formula`); dF/dt normalized to TFmax; Ca2+TR amplitude (reference of the Δ not stated); RNAseq % shares (counts not printed); APD40-30/80-70; and the ADRB1/ADRB2, TNNI3/TNNI1 and MYL2/MYL7 ratios.
- **APD ratio.** It is printed "ADP40-30/80-70" and read as (APD40 − APD30)/(APD80 − APD70), in the order the name prints. The value printed is ">2", which is a bound rather than a value.
- No model is used, so there are no assumption reports, and no proposals were needed.
